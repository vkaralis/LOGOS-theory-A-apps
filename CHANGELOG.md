# Changelog

## [0.5.0] — 2026-10-12

- Package LOGOS A model and event-analysis workflows as an installable Python project.
- Provide independently generated synthetic ANC/dose and PSA records with seed and input hashes.
- Include periodic, finite, constant-family, safety-tail and information-value calculations.
- Include patient-held-out prediction, full-training bootstrap and observation-process diagnostics.
- Add numerical verification, reproducibility comparison and Python 3.12 CI.
- Apply MIT to code and synthetic data, and supply repository topics.
- Name Vangelis D. Karalis as author and copyright holder; add the LOGOS About description and expanded research overview with an explicit synthetic-data notice.
- Suppress embedded creator/software/date metadata in generated figures and use neutral fixed ZIP timestamps.

This is the first public package prepared in this repository. The version number does not imply previous public releases.
